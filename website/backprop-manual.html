Backpropagation Manual

Derivación completa para una red con 2 entradas, capa oculta y nn.CrossEntropyLoss — exactamente lo que PyTorch Autograd computa internamente.

0. Arquitectura y Notación

Red neuronal con la siguiente estructura:

  • Entrada: $x \in \mathbb{R}^{2}$
  • Primera capa afín: $a_1 = W_1 x + b_1$, con $W_1 \in \mathbb{R}^{16\times 2}$, $b_1\in\mathbb{R}^{16}$
  • Activación: $h = \mathrm{ReLU}(a_1) \in \mathbb{R}^{16}$
  • Segunda capa afín (logits): $z = W_2 h + b_2$, con $W_2 \in \mathbb{R}^{2\times 16}$, $b_2\in\mathbb{R}^{2}$
  • Targets: $y \in \{0,1\}$ (índice de clase)
  • Pérdida: nn.CrossEntropyLoss

Para un batch de tamaño $N$:

  • $X \in \mathbb{R}^{N\times 2}$
  • $A_1 \in \mathbb{R}^{N\times 16}$
  • $H \in \mathbb{R}^{N\times 16}$
  • $Z \in \mathbb{R}^{N\times 2}$
  • $y \in \{0,1\}^N$

1. Derivada de CrossEntropyLoss (pérdida → logits)

nn.CrossEntropyLoss() realiza internamente:

  1. $P = \mathrm{softmax}(Z)$
  2. $\displaystyle \mathcal{L} = -\frac{1}{N}\sum_{i=1}^N \log P_{i,y_i}$

Definiendo targets one-hot $Y \in \mathbb{R}^{N\times 2}$, el resultado clave (softmax + NLL combinados) es:

$$\frac{\partial \mathcal{L}}{\partial Z} = \frac{1}{N}(P - Y)$$

Definimos $G_Z := \dfrac{\partial \mathcal{L}}{\partial Z} \in \mathbb{R}^{N\times 2}$.

2. Backprop por la última capa lineal

Forward: $Z = H W_2^\top + \mathbf{1} b_2^\top$

Gradientes respecto a parámetros

$$\frac{\partial \mathcal{L}}{\partial W_2} = G_Z^\top H \qquad \frac{\partial \mathcal{L}}{\partial b_2} = \sum_{i=1}^N G_Z[i,:]$$

Gradiente respecto a la entrada de la capa

$$G_H := \frac{\partial \mathcal{L}}{\partial H} = G_Z W_2$$

3. Backprop por ReLU

Recordando: $H = \mathrm{ReLU}(A_1)$, la derivada es:

$$\frac{\partial H_{ij}}{\partial A_{1,ij}} = \begin{cases} 1 & A_{1,ij} > 0 \\ 0 & A_{1,ij} \le 0 \end{cases}$$

Definimos la máscara $M = \mathbf{1}[A_1 > 0]$. Entonces:

$$G_{A_1} = \frac{\partial \mathcal{L}}{\partial A_1} = G_H \odot M$$

El operador $\odot$ es el producto elemento a elemento (Hadamard). Las neuronas con $A_1 \le 0$ reciben gradiente cero — son las "neuronas muertas".

4. Backprop por la primera capa lineal

Forward: $A_1 = X W_1^\top + \mathbf{1} b_1^\top$

Gradientes respecto a parámetros

$$\frac{\partial \mathcal{L}}{\partial W_1} = G_{A_1}^\top X \qquad \frac{\partial \mathcal{L}}{\partial b_1} = \sum_{i=1}^N G_{A_1}[i,:]$$

Gradiente respecto a la entrada (opcional)

$$G_X := \frac{\partial \mathcal{L}}{\partial X} = G_{A_1} W_1$$

5. Resumen del backward completo

Pasos en orden, desde la pérdida hasta los parámetros:

1$P = \mathrm{softmax}(Z)$ 2$G_Z = \dfrac{1}{N}(P - Y)$ 3$\nabla W_2 = G_Z^\top H$ 4$\nabla b_2 = \displaystyle\sum_i G_Z[i,:]$ 5$G_H = G_Z W_2$ 6$G_{A_1} = G_H \odot \mathbf{1}[A_1 > 0]$ 7$\nabla W_1 = G_{A_1}^\top X$ 8$\nabla b_1 = \displaystyle\sum_i G_{A_1}[i,:]$ 9$G_X = G_{A_1} W_1$  (opcional)
Esto es exactamente lo que PyTorch Autograd computa internamente al llamar .backward().

¿Cómo ejecutar Python?

Intérprete interactivo (REPL)

python

Ejecutar un archivo

python archivo.py

Usaremos Notebooks y Editores

  • Google Colab
  • VsCode

REPL — Read-Eval-Print Loop: el intérprete lee tu código, lo evalúa, imprime el resultado y repite. Ideal para explorar y probar expresiones de forma interactiva.

REPL = Read-Eval-Print Loop. El intérprete lee una línea, la evalúa, imprime el resultado y espera la siguiente. Útil para experimentar rápidamente.
